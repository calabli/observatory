功能

装上就能用，不用改任何配置

不代理请求，也不需要 API 密钥。Observatory 直接读取各工具写在本机的日志，增量扫描，重复扫描不会重复计数。

完整的用量看板

费用、请求、四类 token、缓存命中率和趋势，可按时间、应用、服务商、模型筛选，请求明细支持导出 CSV。

多设备合并统计

局域网自动发现其他电脑，用 6 位配对码连接，按应用选择共享内容，在一张看板里看所有设备的总用量。

托盘快捷面板

点一下任务栏或菜单栏图标，就能看到今日和最近 7 天的费用、请求和各应用用量，不用打开主窗口。

价格可自己维护

四类 token 单价都能编辑，可从 models.dev 一键导入并定期同步；改了价格还能回填历史费用。

活动日志

每次扫描读了哪些文件、读到第几行、新增多少 token，局域网谁来访问过、同步结果如何，都有据可查。

本地网络概览

网卡、IP、网关、DNS 和实时收发速率一目了然；出口 IP 只在你点击时查询。

支持的工具

主流 AI 编程工具都能统计

按各工具的默认日志位置读取，也会遵循它们自己的环境变量（如 CODEX_HOME）。

隐私

你的数据，只在你的电脑上

Observatory 没有账号，没有云端，也不上传任何统计。所有数据存放在本机的 ~/.observatory 目录中。

  • 只读日志，不碰对话只解析用量字段，不导入对话正文、API 密钥或服务商配置。
  • 局域网共享默认关闭开启后必须用一次性配对码配对，随时可以撤销授权。
  • 更新包经过签名应用内更新会校验签名，签名不符的安装包会被拒绝。
  • 开源可审查全部源代码公开在 GitHub 上。
