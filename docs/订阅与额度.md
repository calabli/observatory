# 订阅与额度

在导航栏打开「订阅与额度」：添加订阅时记录名称、Agent、金额、币种、账期、有效日期和每周周期。记录保存在本机观测台数据库，结束日期不包含当日；已停用或不在有效日期内的订阅可在「订阅管理 → 全部订阅」中编辑或删除。

账期与额度周期是两回事：账期说明多久付一次钱（每月、每年，或自定义的「每 N 天」），每周周期说明额度何时重置。自定义账期要填 1–366 之间的天数。

周周期按本机时区和设置的星期、时分秒计算，开始包含、结束不包含。周期会随时间自动滚动；使用上一周期、历史周期下拉框或下一周期查看其他周期。当前周期只统计截至查询时的记录，未来周期不执行查询。

周期导航限制在**订阅有效期内**：与有效期没有交集的周期不覆盖任何订阅额度，不出现在历史下拉里，上一周期与下一周期按钮在到达边界时置灰。

周期本身按订阅有效期**收敛**：开头取「订阅开始时间」与「周周期开始时间」的较晚者，结尾取「周周期结束时间」与「订阅到期时刻」的较早者。订阅在周期中途开始或到期时，只统计被订阅覆盖的那一段，页面会标出收敛前后的范围。

选择「最近天数」可查询今天、最近 7、30、90 天或自定义 1–366 天，包含今天。趋势图可切换 Token、费用和请求，带左侧刻度与悬停提示，最多展示最近 30 个日期；顶部汇总覆盖整个所选范围。查询只读取已采集的数据，最近扫描时间显示在页面底部。

费用与 Token 是所选 Agent 的**本机全部来源**统计，不受局域网共享选择限制。周周期按订阅有效期裁剪，最近天数查询不裁剪；选择完整日期回退时可能包含原周期外的用量，页面会提示。同一 Agent 的多个订阅目前不能按账号区分；订阅金额单独展示，不与估算 API 费用相加。订阅金额按所选币种显示符号（USD `$`、CNY `¥`、EUR `€`），但不做汇率换算——API 费用一律以美元计。订阅日期及金额均为手动维护，不代表服务商账单；官方剩余额度和百分比以服务商页面为准。

若历史记录只剩日汇总，周期边界截断该日期时，页面会显示精度错误，而不是把这部分用量静默算成零。错误里会列出**受影响的日期**，并提供「改用完整日期范围查询」把这些日期整日计入，也可以回到周期查询或切到仍有明细的周期。夏令时导致设置的本地时间不存在时，页面会提示调整周期。

「订阅管理」支持按名称或 Agent 检索，并可按开始日期、名称或金额排序；每行可直接启用或停用，也可以跳到该订阅的用量页查看历史用量。未生效或已停用的订阅同样可以查看用量。页面的位置偏好（当前订阅、标签页、筛选、统计方式、天数、趋势指标）记在本机，重载后恢复。
