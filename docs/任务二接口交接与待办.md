# 任务二接口交接与待办

用户已改为简单配对码方案。当前工作树接入了配对码、局域网同步和远程扫描界面，并已通过本机模拟与双实例测试；尚未进行 Windows/Mac 双机实测。局域网请求使用明文 HTTP，配对码和凭证不提供加密保护，只适用于可信网络。

配对改为一次完成双向登记：两端均需开启局域网共享且能够相互访问，一方生成配对码，另一方输入。无法回连发起设备时配对失败，配对码不被消耗。

## 已有原型

- `src/usage/multiDeviceScan.ts`：通过 `ScanTransport` 注入本机扫描、远端创建/等待任务和同步，固定目标、限制并发、产生逐台状态。状态仅在内存中；传输负责鉴权、任务幂等、超时和校验。
- `src/usage/MultiDeviceScanPanel.tsx`：呈现设备状态、汇总与缓存时间。时间字段 `startedAt`、`completedAt` 使用毫秒；现有 `lastSyncAt` 使用秒。
- `src/usage/DeviceManager.tsx`：生成本机一次性配对码、输入对方配对码及管理授权设备。
- `tests/multiDeviceScan.test.mjs`：以 mock 检查成功、来源错误、未配对、同步失败、并发上限和重复启动。
- `native/src/api.rs`：抽出只扫描本机的 `scan_local`，与后台扫描复用同一把锁，不执行远端同步。
- `native/src/scan_jobs.rs`：内存任务管理器，支持按请求方和幂等键查询、并发任务合并和失败状态；已经接入配对授权和本机扫描。进程重启任务消失，查询显示状态未知；历史任务按一天的期限清理。
